

It is a web application that collects product data from popular e-commerce websites like Amazon and Flipkart and generates intelligent product descriptions using GPT. 
## Features

- Scrapes product details like name, price, image, ratings, etc.
- Generates concise and appealing product descriptions using GPT.
- Easy-to-use interface for browsing and exporting product data.
- Can handle multiple e-commerce platforms.

## Tech Stack

- **Frontend:** HTML, CSS, JavaScript (React optional)
- **Backend:** Node.js / Python (depending on your implementation)
- **Scraping:** BeautifulSoup, Puppeteer, or Cheerio (depending on language)
